# Phase 2 — Send Google call invites as Skyler

## Goal
Future call invites should show Skyler Bossen (skyler.bossen@neurongarage.com) as the sender, and calls should stay on the "Shared NG Franchise Development" calendar.

## How it works
- The calendar we save the event to decides where the call lives. We keep the shared calendar.
- The Google account that creates the event decides who the email comes from. This needs to change from Sam to Skyler.
- Google may still name the shared calendar as the "organizer" inside the invite. The app cannot change this.

## Steps
1. Check access: confirm the shared calendar is shared with Skyler with "Make changes to events" (Sam does this in Google Calendar if it is missing).
2. Connect Skyler's Google Calendar account to the app as a second connection. Sam's connection stays in place.
3. Controlled test: create one test call on the shared calendar using Skyler's account, invite a test email, and check the sender, organizer, Meet link, and portal card. Then delete the test call.
4. If the test looks right: switch future call creation, edits, and cancels to Skyler's connection. Existing calls keep working.
5. If it does not look right: stop and explain the options (for example, a calendar that Skyler owns).

## Estimated turns
1–2 turns.

## Risks and what stays untouched
- Calls that already exist were created by Sam. Editing or canceling them may still need to use Sam's connection, so we keep his connection linked.
- No changes to app emails, the portal, forms, or FDD records.
- Testing: test invite email, Meet link, moving a call, canceling a call, and no duplicate invites.
